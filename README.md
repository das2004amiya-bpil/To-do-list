# Daymark To-Do List

A simple, responsive to-do list for organizing everyday tasks and looking ahead to the week. Built with plain HTML and CSS.

## Features

- Separate checklists for today's essentials and this week's plans
- Interactive checkboxes with a clear completed-task style
- Responsive layout for desktop and mobile screens
- No dependencies, build tools, or installation required

## Getting started

Open `index.html` in a web browser. The page can also be hosted as a static site.

## Using the list

Click a checkbox to mark a task complete. To change the starter tasks, edit the corresponding list items in `index.html`.

Task completion is not saved between page loads. This version does not include task creation, editing, or persistent storage.

## Project files

- `index.html` contains the page structure and starter tasks.
- `styles.css` contains the layout, colors, typography, and responsive styles.

The stylesheet loads DM Sans and Playfair Display from Google Fonts when online, with local system-font fallbacks.
